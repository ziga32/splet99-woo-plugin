# Splet99 Woo

WordPress vtičnik Splet99 za spletne trgovine WooCommerce, ki jih vzdržujemo. Zahteva aktiven WooCommerce.

## Namestitev

1. Prenesi ZIP zadnje izdaje.
2. WordPress → Vtičniki → Dodaj nov → Naloži vtičnik.
3. Aktiviraj **Splet99 Woo**.

## Pravilo

V kodi ni gesel, API ključev ali podatkov strank. Takšne nastavitve se vnesejo v wp-admin posamezne strani.
